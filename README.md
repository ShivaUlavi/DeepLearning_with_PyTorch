# Deep Learning with PyTorch 🚀

This repository is my hands-on learning space for deep learning with PyTorch. It contains notebooks, experiments, and practical examples covering core concepts, model building, and training workflows.

This repo is still a work in progress, and I will be uploading new notebooks and learning material regularly.

## 📚 Current Topics

- Linear regression from scratch
- Neural networks with `torch.nn`
- Image classification with MLPs
- Convolutional neural networks (CNNs)
- Transfer learning and pretrained models
- PyTorch fundamentals and experimentation
