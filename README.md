# Deep Learning with PyTorch 🚀

This repository is a personal learning space for exploring deep learning with PyTorch. It contains a growing collection of notebooks focused on core concepts, model design, training workflows, and practical experimentation across vision and sequence-based tasks.

Each notebook is designed to help build intuition through hands-on examples, from understanding gradients and training loops to applying convolutional and recurrent networks to real-world datasets.

## 📚 Notebook Overview

- `01_linear_regression_scratch_to_autograd.ipynb`  
  Covers linear regression implemented from scratch using PyTorch tensors and autograd, helping to understand gradients, loss functions, and optimization.

- `02_neural_networks_with_nn_module.ipynb`  
  Introduces `torch.nn`, model definition, and training loops for building neural networks in a more structured and reusable way.

- `03_Classifying_Birds_vs_Planes_PyTorch_MLP.ipynb`  
  Uses a simple multi-layer perceptron to classify bird vs. plane images and demonstrates a basic image classification pipeline.

- `04_Going_Deeper_With_Convolutions.ipynb`  
  Explores convolutional layers and how CNNs learn spatial patterns from image data.

- `05_Multiclass_Classification_with_CIFAR10.ipynb`  
  Applies a CNN to the CIFAR-10 dataset for multiclass image classification and introduces more realistic training routines.

- `06_Transfer_Learning_ResNet18_vs_EfficientNetB0.ipynb`  
  Compares pretrained models such as ResNet18 and EfficientNetB0 to understand transfer learning and model adaptation for new tasks.

- `07_character_level_rnn_classification.ipynb`  
  Introduces a character-level recurrent neural network for text classification and explores sequence modeling concepts.

- `08_MNIST_Classification_RNN_GRU_LSTM.ipynb`  
  Demonstrates sequence-based learning with RNN, GRU, and LSTM models on the MNIST dataset.

- `PyTorch_Quickstart_Pretrained_models.ipynb`  
  Provides a quickstart-style exploration of pretrained PyTorch models and common workflows for transfer learning and inference.

- `pytorch_gpu_toy_classifier.ipynb`  
  A lightweight GPU example for understanding device handling, training behavior, and efficient experimentation in PyTorch.
